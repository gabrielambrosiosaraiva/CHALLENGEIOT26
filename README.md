# CHALLENGEIOT26
Projeto desenvolvido para o Challenge FIAP 2026. Protótipo de validação de receitas eletrônicas via RFID integrado ao Node-RED por protocolo serial. Desenvolvido para o Challenge FIAP 2026, o ecossistema IoT simula a auditoria de credenciais veterinárias, acionando alertas físicos (LEDs/Buzzer) e atualizando uma interface web corporativa.
